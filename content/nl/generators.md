---
title: Generators
description: gonestly generate maakt resources, modules, controllers, services, guards, interceptors en getypeerde kolommen, en registreert ze waar ze horen.
---

`gonestly generate` schrijft de code die je anders uit een bestaand onderdeel zou kopiëren, en registreert hem: een nieuwe module wordt in de rootmodule geïmporteerd, en controllers en services worden aan hun module toegevoegd. Je draait het vanaf elke plek in het project.

```sh
gonestly generate resource products
gonestly g controller reports       # g is kort voor generate
```

## Soorten

| Soort         | Maakt                                                                                                                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `resource`    | Een compleet onderdeel: een model, een migratie, getypeerde kolommen, requests met validatie, een service, een controller met routes voor aanmaken, lezen, bijwerken en verwijderen, en een test. |
| `module`      | Een lege module, geïmporteerd in de rootmodule.                                                                                                                                                   |
| `controller`  | Een controller en zijn test, toegevoegd aan de module.                                                                                                                                            |
| `service`     | Een service, toegevoegd aan de providers van de module.                                                                                                                                           |
| `guard`       | Een guard die een bearer token controleert en hem in het [OpenAPI](openapi)-document beschrijft, geëxporteerd voor andere modules.                                                                |
| `interceptor` | Een interceptor die logt hoe lang requests duren, geëxporteerd voor andere modules.                                                                                                               |

De naam mag in elke stijl: `order-items`, `order_items` en `OrderItems` maken allemaal het package `orderitems` in `internal/orderitems`, met het model `OrderItem`, de tabel `order_items` en de routes onder `/order-items`. Kies met `--dir` een andere map.

Generators overschrijven nooit een bestand. Bestaat een van de bestanden al, dan wordt er niets geschreven, en faalt een stap halverwege, dan worden de bestanden die hij al schreef weer verwijderd.

## Een resource

`gonestly generate resource products` maakt:

```text
internal/products/
  module.go           de module, met repository, service en controller
  model.go            het model Product
  columns_gen.go      getypeerde kolommen voor de querybuilder
  requests.go         de requests, met validatie en documentatie
  service.go          de logica, bovenop de repository
  controller.go       GET-, POST-, PUT- en DELETE-routes
  controller_test.go  een test van elke route, tegen SQLite
migrations/
  20261125183712_create_products.up.sql
  20261125183712_create_products.down.sql
  schema.snapshot.json
```

De migratie wordt uit het model geschreven met [schema vanuit je modellen](schema), in de kolomtypes van je database, herkend aan de driver in `go.mod`. Wijzig het model later en `gonestly migrate dev` schrijft de volgende migratie. De test wordt gegenereerd voor SQLite-projecten, waar hij zonder server draait. Start de applicatie en de routes verschijnen in `/docs`.

Een resource heeft een project met een database nodig; maak er een met `gonestly new <map> --database postgres`, `--database mysql` of `--database sqlite`.

## Registratie

Code wordt geregistreerd door de modulebestanden precies aan te passen: het nieuwe onderdeel komt in `Imports`, `Providers`, `Controllers` of `Exports`, en de import wordt toegevoegd. De rest van het bestand, inclusief comments en opmaak, blijft zoals het is. Een generator twee keer draaien registreert nooit iets dubbel.

## Getypeerde kolommen

`gonestly generate columns` schrijft `columns_gen.go` met de kolommen van elke struct met `db`-tags in een package, voor de [querybuilder](queries#de-querybuilder):

```go
// Code generated by gonestly generate columns; DO NOT EDIT.

var ProductColumns = struct {
	ID        sql.Column[int64]
	Name      sql.Column[string]
	CreatedAt sql.Column[time.Time]
}{
	ID:        sql.Col[int64]("id"),
	Name:      sql.Col[string]("name"),
	CreatedAt: sql.Col[time.Time]("created_at"),
}
```

```go
products, err := sql.From[Product](db).Where(ProductColumns.Name.Like("%tea%")).All(ctx)
```

Modellen uit een resource hebben een `go:generate`-regel, zodat `go generate ./...` de kolommen bijwerkt als je een model aanpast:

```go
//go:generate gonestly generate columns
```
