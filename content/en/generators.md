---
title: Generators
description: gonestly generate creates resources, modules, controllers, services, guards, interceptors and typed columns, and registers them where they belong.
---

`gonestly generate` writes the code you would otherwise copy from an existing feature, and registers it: a new module is imported in the root module, and controllers and services are added to their module. Run it from anywhere inside the project.

```sh
gonestly generate resource products
gonestly g controller reports       # g is short for generate
```

## Kinds

| Kind          | Creates                                                                                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `resource`    | A complete feature: a model, a migration, typed columns, requests with validation, a service, a controller with create, read, update and delete routes, and a test. |
| `module`      | An empty module, imported in the root module.                                                                                                                       |
| `controller`  | A controller and its test, added to the module.                                                                                                                     |
| `service`     | A service, added to the providers of the module.                                                                                                                    |
| `guard`       | A guard that checks a bearer token and describes it in the [OpenAPI](openapi) document, exported for other modules.                                                 |
| `interceptor` | An interceptor that logs how long requests take, exported for other modules.                                                                                        |

The name can be written in any style: `order-items`, `order_items` and `OrderItems` all create the package `orderitems` in `internal/orderitems`, with the model `OrderItem`, the table `order_items` and the routes under `/order-items`. Use `--dir` to choose another directory.

Generators never overwrite a file. If one of the files exists, nothing is written, and if a step fails halfway, the files it wrote are removed again.

## A resource

`gonestly generate resource products` creates:

```text
internal/products/
  module.go           the module, with the repository, service and controller
  model.go            the Product model
  columns_gen.go      typed columns for the query builder
  requests.go         the requests, with validation and documentation
  service.go          the logic, on top of the repository
  controller.go       GET, POST, PUT and DELETE routes
  controller_test.go  a test of every route, against SQLite
migrations/
  20261125183712_create_products.up.sql
  20261125183712_create_products.down.sql
```

The migration uses the column types of your database, detected from the driver in `go.mod`. The test is generated for SQLite projects, where it runs without a server. Start the application and the routes appear in `/docs`.

A resource needs a project with a database; create one with `gonestly new <dir> --database postgres` or `--database sqlite`.

## Registration

Code is registered by editing the module files precisely: the new entry is added to `Imports`, `Providers`, `Controllers` or `Exports`, and the import is added. The rest of the file, including its comments and layout, stays as it is. Running a generator twice never registers something twice.

## Typed columns

`gonestly generate columns` writes `columns_gen.go` with the columns of every struct with `db` tags in a package, for the [query builder](queries#the-query-builder):

```go
// Code generated by gonestly generate columns; DO NOT EDIT.

var ProductColumns = struct {
	ID        sql.Column[int64]
	Name      sql.Column[string]
	CreatedAt sql.Column[time.Time]
}{
	ID:        sql.Col[int64]("id"),
	Name:      sql.Col[string]("name"),
	CreatedAt: sql.Col[time.Time]("created_at"),
}
```

```go
products, err := sql.From[Product](db).Where(ProductColumns.Name.Like("%tea%")).All(ctx)
```

Models from a resource carry a `go:generate` line, so `go generate ./...` updates the columns after you change a model:

```go
//go:generate gonestly generate columns
```
